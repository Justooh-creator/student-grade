# EduReport

Build a complete SBA student report card generation app. preload GES curriculum subjects and grading system and also classes range from Kg 1 to kg 2 and Basi 1 -9. When a class is it ts subject rolled out automatically. Report card printed out into pdf A4 size. SBA 3p and Exam 70 total equall 100. grades 1-9 where 9 is the lowest
